# assets/materials

Shared `ShaderMaterial` `.tres` files. Toon surfaces take
`outline_ink.tres` as their `next_pass` for comic ink outlines.

## Character kit

| Material | Use |
|---|---|
| `toon_skin` | Face, neck, hands, forearms |
| `toon_hair` | Hair mass + fringe |
| `toon_jacket` | Torso / shoulders / sleeves |
| `toon_pants` | Pelvis, thighs, shins |
| `toon_boots` | Boots |
| `toon_visor` | Emissive cyan cyber visor |
| `toon_accent` | Belt / jacket neon trim (magenta) |
| `toon_eyes` | Eye plates |
| `toon_mask` | Full face mask (thug kit) |

World: `toon_concrete`, `toon_asphalt`. Legacy `toon_player` kept for old refs.
